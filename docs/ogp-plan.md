#### タスク進捗ログ
- 2025-09-23 (CODEx): TCD113デモを分析し、以下をデザインブリーフとして整理。
  - **ヴィジュアルトーン**: フル幅ヒーロー画像にダークオーバーレイ、左右中央揃えの落ち着いたレイアウト。十分な余白で静謐感を演出。
  - **カラー**: 深い墨色 (#1B1B1B)、焦げ茶 (#3A2F27)、アクセントの渋金 (#C7A25A)、背景の生成クリーム (#F8F4ED)。補助色として深緑 (#1D3B32) を差し色に検討。
  - **タイポグラフィ**: 見出しは明朝体（Shippori Mincho / Noto Serif JP を想定）、本文はNoto Sans JPなどのサンセリフ。英字は大文字＋トラッキングを広めに設定。
  - **モチーフ**: 家紋風ロゴ、縦罫線・細めのボーダー、角丸のないフラットボタン、和紙テクスチャ。画像上に半透明パネルを重ねてタイトルを表示。
  - **写真スタイル**: 寺院の建築、四季の植物、儀式の様子など落ち着いた暖色寄りの写真を採用。画像が無い場合はテクスチャ背景で代替。
  - **OGP適用指針**: 背景にメイン画像、中央寄せでタイトルとカテゴリ、下部に寺院名＋ロゴ。全体に暗めのオーバーレイをかけ、可読性を確保。

## 6. リスクと対策
- **デザイン遅延** → 早期にラフを共有しフィードバックサイクルを短く。
- **Sanity スキーマ変更の影響** → 先にステージング環境で検証し、既存データへのマイグレーションスクリプトを準備。
- **生成コスト増** → `@vercel/og` のキャッシュ利用、`revalidate` 設定を調整。
